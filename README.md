# Cờ Tướng Pro

Đồng hồ cờ tướng chạy trực tiếp trên trình duyệt.

## Đưa lên GitHub Pages

1. Tạo repository tên `co-tuong-pro` trên GitHub.
2. Upload file `index.html` trong thư mục này.
3. Vào **Settings → Pages**.
4. Ở **Build and deployment**, chọn **Deploy from a branch**.
5. Chọn branch `main`, folder `/ (root)`, rồi **Save**.
6. Sau khi GitHub triển khai xong, mở:

https://thuangq.github.io/co-tuong-pro/

Nếu repository để Public, GitHub Pages có thể được truy cập bằng link trên.
